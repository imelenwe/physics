Measurement: from overlap to tr(something · ρ)

One running example: the state |+⟩ = (|0⟩ + |1⟩)/√2, and a bag that gives |1⟩ with 25% chance and |+⟩ with 75% chance.

M1Amplitude is an overlap

The amplitude for outcome m is the overlap ⟨m|ψ⟩, an ordinary dot product between the state and the outcome.

Example

⟨0|+⟩ = (⟨0|0⟩ + ⟨0|1⟩)/√2 = (1 + 0)/√2 = 1/√2

The bra ⟨0| distributes over the sum, as a dot product does. ⟨0|1⟩ = 0 because |0⟩ and |1⟩ are orthogonal.

Recall

What is ⟨1|+⟩, and why? (1/√2: ⟨1| distributes, ⟨1|0⟩ = 0 and ⟨1|1⟩ = 1.)

M2The sandwich ⟨ψ|P|ψ⟩ appears by itself

Probability is amplitude × its conjugate. Regroup that product and a projector pops out in the middle. Nobody chooses to sandwich.

Why

p(m) = |⟨m|ψ⟩|²
     = ⟨m|ψ⟩* · ⟨m|ψ⟩          |z|² = z* · z
     = ⟨ψ|m⟩ · ⟨m|ψ⟩            conjugating an overlap flips it round
     = ⟨ψ| (|m⟩⟨m|) |ψ⟩  =  ⟨ψ|Pₘ|ψ⟩

The state appears twice (ket and bra) because probability is the amplitude times its own conjugate.

Example

p(0 | +) = ⟨+| |0⟩⟨0| |+⟩ = (1/√2)(1/√2) = 1/2
Recall

Why does the state appear twice in ⟨ψ|P|ψ⟩? (The ket carries the amplitude, the bra carries its conjugate; probability = amplitude × conjugate.)

M3A projector is a yes/no question

A projector has only two eigenvalues: 1 (yes, the state is in this subspace) and 0 (no). So ⟨ψ|P|ψ⟩ is the average answer to a yes/no question, which is a probability.

P₀ = |0⟩⟨0| = [[1,0],[0,0]]
P₀|0⟩ = |0⟩   → eigenvalue 1   "yes"
P₀|1⟩ = 0     → eigenvalue 0   "no"
P² = P and P† = P              (asking twice gives the same answer)

It is the quantum version of an indicator in probability theory, where P(event) = average of (1 if the event happens, 0 otherwise).

Recall

Is |0⟩⟨1| a projector? (No: it squares to 0. P² = P fails.)

M4A mixed state is a bag of pure states

Two layers of chance: a classical chance pᵢ of which state is in the box (never squared), then the quantum chance of the outcome given that state.

ρ = Σ pᵢ |ψᵢ⟩⟨ψᵢ|
p(m) = Σ  p(state was ψᵢ) × p(m | ψᵢ)          law of total probability
     = Σ  pᵢ × ⟨ψᵢ|Pₘ|ψᵢ⟩

Example

bag: 25% |1⟩, 75% |+⟩
p(0) = 0.25 × 0  +  0.75 × 1/2  =  3/8

One shot: one state comes out of the bag, is measured once, and gives one outcome. Repeat many times and 3/8 of the shots say 0.

Recall

Why are the pᵢ never squared? (They are classical probabilities already, not amplitudes.)

M5Why the trace: tr(Pρ) is the bag calculation in one formula

ρ packs the bag into one matrix. The projector chooses the question, and the trace adds up what it chose. The diagonal of ρ already combines both layers of chance.

The trick

⟨ψ|A|ψ⟩ = tr(⟨ψ|A|ψ⟩)      the trace of a plain number is the number
        = tr(A |ψ⟩⟨ψ|)      cyclic: tr(ABC) = tr(BCA), move ⟨ψ| to the back
Σ pᵢ tr(P |ψᵢ⟩⟨ψᵢ|) = tr(P Σ pᵢ|ψᵢ⟩⟨ψᵢ|) = tr(Pρ)       the trace is linear

Example (same bag)

ρ = 0.25·[[0,0],[0,1]] + 0.75·½[[1,1],[1,1]] = [[3/8, 3/8], [3/8, 5/8]]
P₀ρ = [[3/8, 3/8], [0, 0]]       P₀ keeps the top row, wipes the bottom
tr(P₀ρ) = 3/8                    same as the bag route
Recall

Which property of the trace turns ⟨ψ|A|ψ⟩ into tr(A|ψ⟩⟨ψ|)? (Cyclic: move ⟨ψ| from the front to the back.)

M6Coherence is basis-dependent; off-diagonals are interference

A measurement reads only ρ's diagonal when it is done in the same basis ρ is written in. In any other basis the off-diagonals (interference) also count. tr(Pρ) works for any question.

The maths

tr(Pρ) = P₀₀·ρ₀₀ + P₀₁·ρ₁₀ + P₁₀·ρ₀₁ + P₁₁·ρ₁₁
P₀ = [[1,0],[0,0]]    → P₀₁ = P₁₀ = 0 → coherences multiplied by 0
P₊ = ½[[1,1],[1,1]]   → P₀₁ = P₁₀ = ½ → coherences switched on

The physics

ψ = a|0⟩ + b|1⟩
⟨+|ψ⟩ = (a + b)/√2                          two paths recombine
p(+)  = ½(|a|² + |b|²) + ½(a b* + a* b)     populations + cross terms

Squaring a sum gives cross terms, like (x + y)² = x² + y² + 2xy. Those cross terms are interference, and they are exactly ρ₀₁ and ρ₁₀. A Z measurement never recombines the paths, so it cannot tell a superposition from a classical coin. An X measurement can. That is why tomography measures in X, Y and Z, and why phase damping (which wipes the off-diagonals) destroys interference.

Example

tr(P₊ρ) = ½(3/8 + 3/8) + ½(3/8 + 5/8) = 7/8
bag check: 0.25 × ½ + 0.75 × 1 = 7/8   ✓
same ρ with the coherences removed: [[3/8,0],[0,5/8]] → tr(P₊ρ) = ½
Recall

A 50/50 classical coin of |0⟩,|1⟩ and the state |+⟩: which measurement tells them apart, and why? (X: it recombines the paths, so the off-diagonal interference shows up.)

M7Projector vs observable: same formula, different answer

tr(something · ρ). A projector gives a probability; an observable gives an average value. An observable is a set of projectors with a number attached to each.

O = Σ λₘ Pₘ                       spectral decomposition (eigenvalues λₘ)
⟨O⟩ = Σ λₘ · p(m) = Σ λₘ tr(Pₘ ρ) = tr(Oρ)

Z = (+1)·P₀ + (−1)·P₁ = [[1,0],[0,−1]]

Example

p(0) = tr(P₀ρ) = 3/8      p(1) = tr(P₁ρ) = 5/8
⟨Z⟩ = (+1)(3/8) + (−1)(5/8) = −1/4
tr(Zρ) = 3/8 − 5/8 = −1/4   ✓  same number, two routes
spread: Var(Z) = ⟨Z²⟩ − ⟨Z⟩² = 1 − 1/16 = 15/16      (Z² = I)
Projector PObservable O
What it isOne yes/no question about one outcomeThe whole measurement: all outcomes plus a value for each
Eigenvalues1 and 0 onlyAny real numbers (the measured values)
tr(·ρ) givesProbability of that outcomeAverage value over many shots
RuleP² = P, P† = PO† = O (Hermitian)
Use it whenYou need the chance of one outcome, or the state after collapse (PρP / tr(Pρ))You need a physical quantity: energy, spin, a Pauli average in RB/CB

Why both exist

  • The projectors are what the device actually does: it reports one outcome per shot. The observable only adds labels to those outcomes.
  • Z and 2Z + 3 use the same projectors, so they are the same measurement with different labels and different averages.
  • Every projector is itself an observable whose values are 1 and 0. That is why "a probability is an expectation value" (of an indicator).
  • The average alone loses information; the full set of projector probabilities gives the whole distribution (spread, not just the mean).
  • On hardware you never measure ⟨Z⟩ directly. You count outcomes and compute it: ⟨Z⟩ ≈ (n₀ − n₁)/N.

Who found this

Max Born gave the probability rule in 1926. John von Neumann introduced the density matrix (1927, independently of Landau) and in his 1932 book wrote expectation values as ⟨A⟩ = tr(ρA), using the spectral theorem (every Hermitian operator is Σ λ P). In 1957 Andrew Gleason proved that, in three or more dimensions, tr(ρP) is the only consistent way to assign probabilities to projectors.

An observable is a list of yes/no questions with a number attached to each answer. tr(Pρ) is a probability, tr(Oρ) is that list averaged.

Recall

Write Z as a sum of projectors, then get ⟨Z⟩ from p(0) and p(1). Why is tr(Zρ) not p(0)? (Z = P₀ − P₁, ⟨Z⟩ = p(0) − p(1). Z has eigenvalues ±1, so it returns an average, not a probability.)

M8So what is the true nature of the state?

The state is ρ itself, an operator that does not need a basis. A matrix is only how ρ looks in one chosen basis. What is real is the full list of answers ρ gives to every possible question, tr(Pρ) for every P.

Example: the same ρ in two bases

Z basis (|0⟩,|1⟩):   [[3/8, 3/8],         ± basis (|+⟩,|−⟩):   [[7/8,  −1/8],
                      [3/8, 5/8]]                               [−1/8,  1/8]]

Same state, different off-diagonals (3/8 vs −1/8). Diagonal versus off-diagonal is a property of the basis you chose, not of the state. Quantities that do not change with the basis describe the state itself:

  • Eigenvalues of ρ: the bag in its own natural basis, the one basis where ρ has no off-diagonals.
  • Purity tr(ρ²): 1 for a pure state, ½ for the maximally mixed qubit.
  • Bloch vector length |r|: 1 on the surface (pure), smaller inside (mixed), 0 at the centre.

Example (our ρ)

r = (2·Re ρ₀₁, −2·Im ρ₀₁, ρ₀₀ − ρ₁₁) = (3/4, 0, −1/4)
|r| = √10 / 4 ≈ 0.79                  inside the ball: mixed
eigenvalues = (1 ± |r|)/2 ≈ 0.895, 0.105
tr(ρ²) = (1 + |r|²)/2 = 13/16         same in both bases above

Many different bags give this same ρ, and all of them give identical statistics for every measurement. Only ρ is physical; the story of how the bag was filled is not.

Recall

Name three things about ρ that no change of basis can alter. (Eigenvalues, purity tr(ρ²), Bloch length |r| — and every probability tr(Pρ).)

Channels and Kraus operators

K1Kraus operators: none keeps the trace, all of them together do

Each K is one thing the noise might do. A single K is not unitary and loses trace. The whole set keeps trace because Σ K†K = I.

ρ → Σ K ρ K†                     K on the left, K† on the right
tr(Σ K ρ K†) = tr(Σ K†K ρ)       cyclic
             = tr(I ρ) = 1       needs Σ K†K = I
tr(Kₖ ρ Kₖ†) = pₖ              each piece alone: probability of outcome k

Example (amplitude damping on |1⟩⟨1|, decay chance γ)

K₀ = [[1,0],[0,√(1−γ)]]   → trace 1 − γ   "no decay"
K₁ = [[0,√γ],[0,0]]       → trace γ       "decayed"
                              sum = 1 ✓

One Kraus operator only: K†K = I, so it is a unitary. What gets lost to the environment is information (which K happened), not probability. Averaging over the unknown outcome is what turns a pure state into a mixed one.

Recall

Why is the single-K case always unitary? (Completeness with one term gives K†K = I.)

K2Kraus operators belong to a time window

Paulis are fixed matrices. Kraus operators describe what the noise did over a chosen interval Δt, so they change when Δt changes. The rates are what is fixed. Kraus sets are also not unique.

K₀(Δt) = [[1,0],[0,√(e−ΓΔt)]]      K₁(Δt) = [[0,√(1−e−ΓΔt)],[0,0]]
Pauli channel:  Kₖ = √(pₖ(Δt)) · Pₖ  fixed shape, weight grows with time

Analogy: K is the distance covered in five minutes, the rate is the speed. Lindblad is the equation written in speeds.

Recall

What do K₀ and K₁ become as Δt → 0? (K₀ → I, K₁ → 0: nothing happens.)

K3Memory breaks the chopping, not the Kraus form

Non-Markovian noise still has a valid Kraus set from 0 to t, with Σ K†K = I (as long as qubit and environment start uncorrelated). What it lacks is one identical channel per step dt.

Markov:   Φ(t + s) = Φ(t)·Φ(s)      semigroup: chop into identical steps → Lindblad
Trotter:  e−iHt ≈ (e−iH₁dt e−iH₂dt)r     computing trick, always allowed

Trotter is a numerical method for a closed system, which never has memory. Markov is a physical assumption that can be false. With memory you can still chop if you keep the environment in the picture and trace it out only at the end. If qubit and environment start entangled, even the single overall Kraus description can fail (process tensors handle that).

Non-Markovian doesn't break Kraus or completeness. It breaks "the same channel every step". In CB that shows up as decays that are not a single clean exponential.

Recall

Trotter vs Markov: which is a trick and which is an assumption? (Trotter = computing trick, always allowed; Markov = physical assumption, true or false for the hardware.)

Lindblad: what to take away

L1The Lindblad equation is rotation plus loss, with no memory

The state changes by a reversible rotation from the Hamiltonian H, plus an irreversible loss from jumps Lₖ happening at rates γₖ. The same rule applies at every instant: the environment forgets after each step.

dρ/dt = −i[H, ρ]  +  Σₖ γₖ ( Lₖ ρ Lₖ† − ½ Lₖ†Lₖ ρ − ½ ρ Lₖ†Lₖ )
         rotation              loss (the dissipator)
         reversible            irreversible
  • H is Hermitian, not unitary. It generates the unitary e−iHt, which appears in the solution, not in the equation (as dx/dt = −kx is solved by e−kt).
  • Lₖ ρ Lₖ† is the jump itself. The two −½ terms are the "no jump happened" branch shrinking to balance it, so the trace stays 1.
  • With every γₖ = 0 it reduces to the closed system, dρ/dt = −i[H, ρ].
Recall

Which term is reversible, and what keeps the trace at 1? (The commutator is reversible; the two −½ terms balance the jump term.)

L2One tiny step: "nothing happened" is close to I, a jump carries √dt

Over a tiny time dt, the no-jump branch is K₀ = I + M·dt (zero time, nothing happens). A jump is Kₖ = √(γₖ dt)·Lₖ, because rate × time = probability and amplitude = √probability.

p(jump k in dt) = γₖ · dt · tr(Lₖ†Lₖ ρ)
for L = σ₋:   excited |1⟩ → γ dt      ground |0⟩ → 0      |+⟩ → γ dt / 2

The Kraus operators belong to that window dt; the rates γₖ and the shapes Lₖ are the time-independent physics.

Recall

Why does the square root sit on K and not on the probability? (K is an amplitude; probability = amplitude².)

L3Loss is fixed by trace preservation; rotation is free and is the Hamiltonian

Any square matrix splits uniquely as M = A + iB with A and B Hermitian, the matrix version of z = Re + i·Im with † in place of *. In K₀, keeping the trace at 1 fixes A (the loss). B is left free, and it is the Hamiltonian: B = −H.

A = (M + M†)/2       B = (M − M†)/(2i)       A† = A,  B† = B
A = −½ Σₖ γₖ Lₖ†Lₖ        (from Σ K†K = I)
example:  σ₋ = [[0,1],[0,0]] = X/2 + i·Y/2

This is not "take the real part of each entry": σ₋ has only real entries but is not Hermitian. Hermitian does not mean diagonal either: X is Hermitian with an empty diagonal.

Recall

Which part of K₀ shrinks and which rotates? (A shrinks; iB rotates and becomes the Hamiltonian.)

L4Choose L to be the jump you believe happens

The jump operator encodes the physics. Energy relaxation, where |1⟩ falls to |0⟩: L = σ₋ = |0⟩⟨1|. Random phase kicks: L = Z.

σ₋|1⟩ = |0⟩      σ₋|0⟩ = 0          only goes down: a cold environment never gives energy back
Z|0⟩ = |0⟩       Z|1⟩ = −|1⟩        flips the relative phase, leaves the populations alone

X would also lift |0⟩ to |1⟩ (heating), the wrong physics for a cold qubit. "Amplitude damping" names the whole channel: the excited-state amplitude and its energy drain away.

Recall

Why not L = X for relaxation? (X also pumps |0⟩ up to |1⟩.)

T1 and T2

Write the qubit state as ρ = [[ρ₀₀, ρ₀₁], [ρ₁₀, ρ₁₁]], with H = 0 and one jump operator. ρ₀₀ and ρ₁₁ are the populations of |0⟩ and |1⟩; ρ₀₁ and ρ₁₀ are the coherences. Orange marks populations (T1), violet marks coherences (T2).

T1Amplitude damping: populations decay at γ, coherences at γ/2

With L = σ₋ at rate γ, the excited population drains into |0⟩ as e−γt, and the coherence fades at half that rate.

What the equation gives, entry by entry

dρ/dt = γ [[  ρ₁₁,      −ρ₀₁/2 ],
           [ −ρ₁₀/2,    −ρ₁₁   ]]
Excited populationρ₁₁(t) = ρ₁₁(0)·e−γt|1⟩ drains away
Ground populationρ₀₀(t) = 1 − ρ₁₁(0)·e−γtwhat leaves |1⟩ lands in |0⟩
Coherenceρ₀₁(t) = ρ₀₁(0)·e−γt/2fades at half the rate

Reading off the times: populations decay as e−t/T1, so T1 = 1/γ. Coherences decay as e−t/T2, so T2 = 2/γ = 2·T1.

Recall

Starting in |1⟩, how much is left in |1⟩ after a time T1? (e−1 ≈ 37%.)

T2Phase damping: populations stay put, coherences decay at 2γφ

With L = Z at rate γφ, nothing moves between |0⟩ and |1⟩; only the off-diagonals shrink. Interference is lost while the populations are untouched.

What the equation gives (using Z² = I)

dρ/dt = γᵩ (ZρZ − ρ) = γᵩ [[    0,     −2ρ₀₁ ],
                          [ −2ρ₁₀,       0   ]]
Populationsρ₀₀, ρ₁₁ constantno energy lost: on its own this noise gives T1 = ∞
Coherenceρ₀₁(t) = ρ₀₁(0)·e−2γφtonly the phase information fades

So T2 = 1/(2γφ). On the Bloch ball the state slides in toward the Z axis.

Recall

Does phase damping change the probability of measuring 0? (No: it only changes the off-diagonals, which a Z measurement never reads.)

T3Both together: rates add, so T2 can never exceed 2·T1

With both noises the decay rates add. The coherence feels γ/2 from relaxation plus 2γφ from dephasing, so T2 ≤ 2·T1, with equality only when there is no pure dephasing.

NoisePopulation rate 1/T1Coherence rate 1/T2
Amplitude damping (γ)γγ/2
Phase damping (γφ)02γφ
Bothγγ/2 + 2γφ
The rule1/T2 = 1/(2·T1) + 2γφγφ ≥ 0, so 1/T2 ≥ 1/(2·T1)
The boundT2 ≤ 2·T1equal only with no pure dephasing

Every qubit's measured T1 and T2 obey this bound. A T2 well below 2·T1 means extra dephasing, for example from noise in the qubit's frequency.

Recall

A qubit has T1 = 100 µs. What is the largest T2 it can have, and when? (200 µs, only with no pure dephasing.)

T4T1 is a time constant, not "the time to decay"

T1 is the time constant for energy loss. In each period of T1, the excited population that remains drops to 37%.

Example (start in |1⟩, T1 = 100 µs)

Why not report "the time to decay"?

An exponential never reaches 0. Thus "the time to decay" has no single value. Each cut-off gives a different time:

time to reach fraction f = T1 × ln(1/f)
50% → 0.69 × T1      10% → 2.3 × T1      1% → 4.6 × T1      0% → never

T1 gives all of these times. Radioactive half-life works the same way.

Rate or time?

The rate γ = 1/T1 holds the same information. Experimentalists report times, because you can compare a time with a gate time. Theorists use rates, because rates add (T3).

T1 describes one clean exponential. A real decay can be different (T6).

Recall

T1 = 50 µs. What fraction remains at t = 100 µs? (t/T1 = 2, so e−2 = 0.14.)

T6How IBM measures T1 and T2

IBM reports fitted time constants from calibration runs. Each fit assumes one exponential.

T1 procedure (inversion recovery)

  1. Prepare the qubit in |1⟩.
  2. Wait for a delay τ.
  3. Measure the qubit.
  4. Repeat steps 1 to 3 for many values of τ.
  5. Fit P(|1⟩) = A·e−τ/T1 + B. A and B absorb the SPAM errors.

T2 procedure (Hahn echo)

  1. Prepare the qubit in |+⟩.
  2. Wait for τ/2.
  3. Apply an X gate. The X gate cancels slow frequency drift.
  4. Wait for τ/2.
  5. Measure in the X basis.
  6. Fit the decay of the coherence. The fit gives T2.

If you remove step 3, the experiment is a Ramsey experiment. It gives T2*, which is shorter than T2.

The values change from day to day. Small defects in the chip (two-level systems) change with time. These defects are an environment with memory. A large gap between T2* and T2 also shows slow noise.

T1 and T2 are time constants of fitted exponentials. The fits assume Markovian decay. The daily drift is evidence of slow, non-Markovian noise.

Recall

What does the X gate in the middle of the echo do? (It cancels slow, steady frequency drift, so echo T2 is longer than Ramsey T2*.)

Benchmarking

All three methods measure how fast a signal decays with the sequence length m. SPAM errors change only the start height, not the decay rate.

B1Standard randomized benchmarking (RB)

RB gives one error number for a whole gate set. A random Clifford twirl turns any noise into depolarizing noise. Thus the survival decays as one exponential.

Procedure

  1. Prepare |0⟩.
  2. Apply m random Clifford gates.
  3. Apply the one Clifford gate that undoes the sequence.
  4. Measure. Record the probability of |0⟩.
  5. Repeat for many random sequences and many values of m.

Rule

F(m) = A · p^m + B               A and B absorb SPAM
r = (d − 1)(1 − p)/d             average error per Clifford
one qubit (d = 2):  r = (1 − p)/2

Example

p = 0.998  →  r = (1 − 0.998)/2 = 0.001   (0.1% per Clifford)

RB gives one average number. It does not tell you which error happened.

Recall

Why does twirling give one exponential? (The Clifford twirl turns any noise into depolarizing noise, which shrinks the Bloch ball by p at each step.)

B2Interleaved RB (one specific gate)

Interleaved RB puts the target gate G after each Clifford. The extra decay is the error of G.

… C₁ → G → C₂ → G → …     →  decay p_G
r_G ≈ (d − 1)(1 − p_G / p)/d

The formula is an estimate, not an exact value. It can be wrong when the errors of G and of the Cliffords interact.

Recall

Which two decays do you compare in IRB? (p from standard RB and p_G from the interleaved run.)

B3Cycle benchmarking, and where memory enters

CB uses a Pauli twirl around one cycle. Each Pauli decays at its own rate. The average of these rates gives the process fidelity of the cycle.

random Paulis → [cycle] → random Paulis → [cycle] … m times
each Pauli P decays as  λ_P^m
process fidelity F = average of λ_P        my Fez result: F = 0.9150 on qubits (38, 49)

The shared assumption

RB, IRB and CB all assume the same noise at every step. This is the no-memory (Markov) assumption of Lindblad (L1, K3). This assumption gives the single exponential.

Noise with memory breaks "the same noise at every step". Then the decay is not one clean exponential. DiffusionCB reads this shape from the raw CB data and infers the memory (δ).

Twirling makes any Markovian noise decay as one exponential. RB reads one rate. CB reads one rate per Pauli. Memory breaks the single exponential, and DiffusionCB measures that.

Recall

Which twirl does CB use, and what does it give? (A Pauli twirl. It gives a Pauli channel, with one decay rate per Pauli.)

Error correction (PH5842, L11–L16)

Running example: the 3-qubit bit-flip code. Codewords |0⟩L = |000⟩ and |1⟩L = |111⟩. Errors {I, X₁, X₂, X₃}.

Q1Knill–Laflamme: each error goes to its own room

A code can correct a set of errors if and only if P Ei† Ej P = αij P for all pairs. The right side is αij times P, not only αij.

Example: compute α for the 3-qubit code

P = |000⟩⟨000| + |111⟩⟨111|

α₁₂:  E₁†E₂ = X₁X₂.   X₁X₂|000⟩ = |110⟩,  X₁X₂|111⟩ = |001⟩.
      Neither result is in the code.  →  P X₁X₂ P = 0  →  α₁₂ = 0
α₁₁:  E₁†E₁ = X₁X₁ = I.   P I P = P  →  α₁₁ = 1

α = the 4 × 4 identity matrix

An operator acts only on what it touches. In X₁X₂·|b⟩⟨b|, the operator acts on the ket |b⟩. The bra ⟨b| stays the same.

ErrorRoom (where the code goes)
nonespan{|000⟩, |111⟩}
X₁span{|100⟩, |011⟩}
X₂span{|010⟩, |101⟩}
X₃span{|001⟩, |110⟩}

The two conditions inside the equation

⟨i_L| E_a† E_b |j_L⟩ = α_ab · δ_ij
  1. δij: errors keep different codewords orthogonal. The errors do not mix 0L and 1L.
  2. αab is the same for every codeword. The syndrome shows the error, but it does not show the data.

αij ≠ 0 for i ≠ j does not stop correction. It means that the errors overlap. You can choose a new error set without overlap (Q2).

Errors must keep codewords orthogonal, and must affect every codeword the same way. Then the syndrome shows the error but not the data.

Recall

What is α₀₁ = P·I·X₁·P? (0: a single X₁ takes |000⟩ out of the code.)

Q2What "diagonalise α with a unitary" means

Every Hermitian matrix has one basis where it is diagonal. A unitary U is the rotation into that basis: H = U·D·U†.

Example

X = Had · Z · Had            (Had = Hadamard gate)
|0⟩,|1⟩ basis:  X = [[0, 1], [1, 0]]     all off-diagonal
|+⟩,|−⟩ basis:  X = [[1, 0], [0, −1]]    diagonal

Rule for QEC

  1. α is always Hermitian. The dagger swaps i and j and conjugates the number.
  2. Thus a unitary u makes α diagonal.
  3. The new errors Fk = Σ u·E describe the same noise. Kraus sets are not unique (K2).
  4. With a diagonal α, no two new errors overlap. Each error goes to its own room.

The rest of the proof, one line each

F_k P = √d_kk · U_k P        on the code, each error is a scaled unitary (polar decomposition)
P_k = U_k P U_k†             the room of error k (a projector)
R_k = P U_k†                 recovery: find the room, then rotate back

"Diagonal" depends on the basis, as in M8. An off-diagonal α means overlapping errors in the chosen error set. It does not mean that the errors cannot be corrected.

Recall

Why must α be Hermitian for the proof? (Only then does a unitary always make it diagonal.)

Q3Paulis are enough, and the 5-qubit limit

If a code corrects I, X, Y and Z on a qubit, it corrects every error on that qubit. One logical qubit needs at least 5 physical qubits.

Example: discretisation

any single-qubit error:  E = c₀·I + c₁·X + c₂·Y + c₃·Z
amplitude damping:       σ₋ = (X + iY)/2
Y = i·X·Z
  1. The Paulis are a basis for all 2 × 2 matrices.
  2. The Knill–Laflamme condition is linear. If it holds for each Pauli, it holds for any sum of them.
  3. The syndrome measurement collapses the sum onto one Pauli. Then you undo that Pauli.

Example: Hamming bound

(number of rooms) × (size of each room) ≤ (total space)
     (1 + 3n)     ×        2^k          ≤      2^n         (k = 1 logical qubit)

n = 4:  (1 + 12) × 2 = 26  >  16    fails
n = 5:  (1 + 15) × 2 = 32  ≤  32    fits exactly
  • 1 room for "no error". 3n rooms for X, Y or Z on one of the n qubits.
  • Each room holds a full copy of the code space. One logical qubit has 2 codewords, so each room has size 2.
  • At n = 5 the space is exactly full. Thus the [5,1,3] code is a "perfect code".

The bound counts orthogonal rooms. Some codes ("degenerate codes") let two errors share a room, and the simple count does not apply to them.

Recall

Why is there a factor 2 in 2·(1 + 3n)? (Each room must hold both codewords, so each room is 2-dimensional.)

Q4A stabilizer is a check

A stabilizer is a Pauli check. Every code state passes it with the value +1. The code is the set of all states that pass every check.

Example: the 3-qubit code

g₁ = Z₁Z₂     "qubit 1 = qubit 2"      gives +1 if they agree, −1 if not
g₂ = Z₂Z₃     "qubit 2 = qubit 3"

pass g₁:            |000⟩, |001⟩, |110⟩, |111⟩     8 → 4
pass g₁ and g₂:     |000⟩, |111⟩                   4 → 2

Rule

P = (I + g₁)/2 · (I + g₂)/2          each (I + g)/2 is a projector (M3, M7)
dimension of the code = 2^(n − r)     r = number of independent checks

Generators

Generators are the smallest set of checks that give all the other checks. If qubit 1 = qubit 2 and qubit 2 = qubit 3, then qubit 1 = qubit 3. In operators: Z₁Z₂ · Z₂Z₃ = Z₁Z₃. You measure only the generators.

Why use stabilizers

  • Codewords need many terms. The 5-qubit |0⟩L has 16 terms. Stabilizers need only n − k Pauli strings.
  • The checks are the syndrome measurement.
  • To find an error, you compare letters. You do not multiply matrices.

A check can only see errors that clash with it. Some errors pass all checks (Q5).

Recall

The code has n = 3 and r = 2 checks. What is the dimension of the code? (23−2 = 2.)

Q5Normalizer: errors that pass every check

An error is detected if it anticommutes with some check. An error in the normalizer, but not in the stabilizer, passes every check and still changes the data. This is a logical error.

The letter rule

X and Z on the same qubit anticommute:  XZ = −ZX
count the qubits where E has X and g has Z
odd count  → anticommute → check reads −1 → detected
even count → commute     → check reads +1 → not seen

Why P F P = 0 when F anticommutes with g

P = gP = Pg
PFP = P g F P = −P F g P = −PFP     ⇒   PFP = 0   (α = 0 in Q1)

The distance d is the smallest number of qubits that a logical error touches. The code corrects up to (d − 1)/2 errors.

For the bit-flip code, a single Z₁ also commutes with all the Z checks. It changes the sign of |111⟩. Thus this code cannot correct phase errors. Shor's code fixes this.
